## 产品想法

让一位有生命感的小魔女融入创作者原本的浏览、资料搜集与开脑洞过程。她随着指针回应用户，通过扫帚、魔杖和魔法书帮助留下材料与念头。产品希望好玩、有帮助、强大，尽量复用已有习惯，让用户决定灵感的用途。
