## 过程中的失败与处理

- 新增TXT浏览器测试先因“灵感熔炉”入口不存在超时，确认了缺少实现的失败基线。
- 初次沙箱浏览器命令发生本机端口访问/绑定问题，按工具授权流程在沙箱外运行。API健康返回service=wisp，model_connected=false、jobs_enabled=false。未停止用户服务。
- React 19的useRef缺少初始值导致TypeScript失败，改为显式undefined联合类型后通过。
- 浏览器测试曾用文本断言检查标题input，改为toHaveValue；窗口恢复用例改为等待现有150ms布局防抖实际写入后刷新。
- 审查发现未打开材料也被adoptMaterials忽略远端更新。新增用例实际复现旧内容不刷新，修复为仅保护已打开窗口/待保存/失败草稿，保存后广播；专项由失败转通过，最终全量包含该用例。
- 数据审查指出迁移fixture使用新版快照导致覆盖不足。已显式去除旧快照source/origin，并补充移出保留running关注任务、已保存结果与active关注。

## 覆盖范围

新增单元用例覆盖严格UTF-8、BOM、LF换行、emoji/UTF-16长度、20MB字节边界、NUL/空白、标题代理对边界、来源副本冻结；事务内12成员并发限制、相同ID幂等/不同内容拒绝、成员写入失败回滚；v5文档、偏好、联合结果、任务、关注及未知来源保留；旧材料超长正文仍可保存。

新增浏览器用例：
1. 粘贴后不自动开窗；活动B旧选区不混入A全文；三能力与Summon；刷新、移出/重新加入、按需窗口恢复。
2. TXT错误编码拒绝、BOM/换行预览、改标题保留原文件名。
3. 新建空白自动开一个窗口、跨页出现、空白禁用能力、冲突草稿刷新列表不被覆盖。
4. 首次保存故障保留输入，重试只有一份材料。
5. 第13份拒绝且不落盘、移出释放名额、全部列表仍保留材料。
6. 导入材料Check授权关注后，移出仍关注Wisp保存版本，回信保留文件来源，可停止。
7. 未打开材料同步远端保存并可接续编辑；已打开编辑器仍使用原版本保护。
8. 新增表单Escape保留输入、Alt+M不打开另一面板、列表切换不触发联合提议。

原有35项浏览器流程继续通过，包含四项两份联合整理及四项持续关注流程。均使用独立浏览器上下文和明确测试材料/故障注入，不是用户数据或研究结果。

## 剩余限制

- 仅单份全文处理；联合仍固定两份。没有任意多材料汇总。
- 仅UTF-8 TXT文件选择；暂无GBK自动识别、拖放、DOCX/PPTX/XLSX/PDF、Canvas或当前文档复制入口。
- 熔炉最多12成员，全部材料可超过12；移出不删除，暂无永久删除或完整备份导出。
- TXT仅导入副本，不持续读取磁盘文件。持续关注仍要求发起页打开，刷新/关闭中断，不自动恢复。
- 已打开材料不强制同步其他页面编辑，出现冲突需复制草稿再载入；不做实时协作。
- 布局沿用150ms防抖，立即刷新未落盘布局可能不恢复；材料与布局分别保存。
- 导入预览在内存，未确认输入无持久化保证。读取/解码不使用独立Worker，不宣称大文件性能已测量。
- 仅本机Chrome自动化与桌面截图验收，未覆盖Safari/macOS/移动端/真实辅助技术或长期休眠。
