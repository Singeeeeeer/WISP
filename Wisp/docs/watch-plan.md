# Check 后持续关注实施计划

用户授权，2026-10-17；仅独立 Wisp，本地规则，无模型、无部署。

成功保存主动 Check（含一次性 Scout Bat）后，可提出持续关注邀请；规则不支持的结果不主动邀请。复用单条展示、60 秒冷却、十分钟过期和版本校验。同材料本会话最多邀请一次，拒绝、取消、完成或过期（包括材料变化失效）后不反复邀请，自动检查回信不触发新提议。

接受邀请仅打开全文范围确认；保存确认后，以当前已保存版本为起点，关注同 ID 文本的未来已保存版本。发起页面持有按材料的 Web Lock；其他标签页可查看、停止，但不能重复执行或自动接管。发起页关闭/刷新后，恢复时标为已中断，不自动恢复关注；可再次明确确认。浏览器休眠期间不承诺实时响应。

运行时每 500ms 读取本地已保存状态，版本稳定至少 750ms 后提交检查，单关注最多一个检查进行中，期间编辑合并至最新版本。每版本最多提交一次，失败不无限重试；空/超限版本记录跳过原因，下一有效新版本继续。停止关注原子取消 pending 关联任务，迟到回信不能覆盖取消；已完成回信保留。

复用 Scout Bat Worker、任务锁、回信展示与 Familiars；关注记录与任务以 watchId 关联，右侧标记显示关注数。IndexedDB v5 增加 watches 仓库，保留所有旧数据。任务入队与关注 lastVersion 同事务，确认与材料版本对照、停止与入队互斥。Helpful proposals 关闭只停提议，不撤销已经明确授权的关注。
