## WP-03 原始实现（历史）

| 行为 | 本轮结果 |
| --- | --- |
| 左右／上下／斜向 | 左右镜像，最大约 18° 俯仰；停止保向 |
| 微抖动 | 约 3px 水平独立累计；避免细步斜向被纵向阈值清零 |
| 角色连续性 | 同一个 Companion DOM 从 witch 切为 casting；移除法阵中央第二只角色 |
| 施法位置 | 角色、真实杖尖、冻结点击点和内移后的法阵共用 magic-layout |
| 杖尖标定 | casting viewBox 为 (341.5,55,270,260)，局部杖尖 (254.5,45)，镜像为 (15.5,45) |
| 光效 | 约 250ms 的尖端亮起→光痕→底纹扩散／入口淡入；按钮命中位置固定 |
| 操作 | 保留右键／辅助点按、Q、底部基础能力；支持动画中点选、Esc、环外取消 |
| 边界 | 菜单与角色限制在可见区；原点击点保留，光痕连接内移菜单；resize 重新约束 |
| 减少动态 | 系统或设置生效，静态举杖／菜单，无光痕和展开动画；隐藏角色仍可选择能力 |

正常位置杖尖距点击点约 7–12px，让短光痕可见。边缘优先让角色位于四入口中央空区；光痕连接真实点击位置。既有跟随、悬浮、编辑／拖选／窗口操作让位保留。没有增加完整八方向位图或任务动画。

## 复现

在 Wisp 目录使用可用 Node 运行：

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/@playwright/test/cli.js test --config playwright.companion.config.ts
```

单元测试以 Vitest API 执行，避免环境文件加载：

```javascript
import { startVitest } from 'vitest/node';
const context = await startVitest('test', [],
  { config: false, root: 'apps/web', watch: false }, { envFile: false });
await context.close();
```

生产预览使用 Vite API，`configFile:false, envFile:false`，root 为 apps/web，outDir 为 Wisp/dist；清空输出前检查绝对路径仍在指定 Wisp/dist 内。测试前端端口 15290 使用同样的隔离方式，不配置 API 代理。新专项路由拦截 `/api/**`，未读取 `.env` 或调用模型。历史 magic-ring.png 在测试后恢复原字节。
