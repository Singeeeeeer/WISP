# Wisp · 本地能力、一次性使魔与主动提议

独立浏览器虚拟桌面。React + TypeScript + Vite + Zustand；IndexedDB 保存本地材料；FastAPI 提供 Gemini Check、Understand、Create 和 Canvas 关系发现接口。本地 Web Worker 保留本地一次性任务与已授权持续关注；三种基础能力和对应的一次性使魔均可显式选择 Gemini。Canvas 仅在明确点击“寻找联系”时调用 Gemini。没有持久服务端任务、浏览器扩展或部署。

## 本机启动

依赖已安装在 Wisp/node_modules 与 Wisp/.venv。使用两个 CMD 窗口分别执行完整路径：

```bat
E:\dsr_version1\DeepSpaceReceiver\Wisp\start-web.cmd
```

```bat
E:\dsr_version1\DeepSpaceReceiver\Wisp\start-api.cmd
```

然后打开 http://127.0.0.1:15178 。前端独立启动也能编辑；后端影响 API 状态和 Gemini 执行，本地编辑与本地规则仍可独立使用。不要通过双击 dist/index.html 使用，浏览器存储与资源需要 HTTP 来源。脚本不会自动打开浏览器；Ctrl+C 停止服务。

脚本中的 Node 路径适用于本机 C:\Program Files\nodejs；转移到其他电脑需调整。后端依赖锁定在 requirements.lock.txt；前端用 package-lock.json 与 npm ci 复现。Python 3.11，Node 22+；浏览器自动化配置使用已安装的 Chrome。

## 操作

1. 修改正文，等待窗口右上角“已保存”。刷新可恢复。
2. 选中文字或定位文档，点击“基础能力” → Check → 核对材料 → “运行本地检查”。结果显示疑点与原文依据，或明确说明规则不支持/未发现疑点。顶栏“处理记录”可找回已保存结果。
3. Summon 选择使魔、核对材料后点击“召唤使魔”。可继续编辑其他文档；右侧“查看使魔任务”打开魔法书 Familiars，查看回信或收好记录。
4. 工作面右键或非输入状态 Q 在光标位置打开魔法环；同一魔女切换举杖，角色与菜单共用冻结锚点和边界布局。真实杖尖光效连接点击点与内移法阵，动画约 250ms，期间可点选或取消；减少动态直接显示静态姿势和菜单。展开时固定，收起后继续跟随。上 Understand、右 Check、下 Create、左 Summon。方向键定位，Tab 循环、Enter 选择、Esc 或点击环外关闭；正文右键打开能力菜单；Shift+右键保留浏览器原生菜单。
5. 非输入状态 Alt/Option+M 打开魔法书，Esc 收起面板；窗口底部程序坞按钮用于恢复窗口。

多标签页冲突时复制未保存草稿，再重新载入最新文档；“重试保存”不会绕过版本检查。浏览器存储被清除后，本地草稿不会保留。

## PDF-01 · Canvas 白板与关系（2026-10-18）

底部程序坞的 Canvas 打开 1600×1200 工作面。便笺为独立纯文本材料，支持新增、编辑、移除、拖动及移动按钮的方向键操作；260×190 便笺的位置限制为 x=0…1340、y=0…1010。Shift 点选或勾选最多两张，侧栏展示选定标题与正文。便笺不自动加入熔炉或旧文档列表。

Helpful proposals 开启时，两张非空便笺稳定选中后提出邀请，并与既有提议共用展示冷却；白板隐藏或被其他面板阻挡时不展示。仅选择、停留或点击“暂时不用”均不调用模型；关闭 Helpful proposals 仍保留手动“寻找联系”按钮。拒绝后当前页面内同一便笺对及内容版本不再主动提议。

点击“寻找联系”发送 `POST /api/connections`，请求包含提交 ID 和两个不同便笺的 `{id, version, title, text}` 副本；正文非空，每张与两张合计均不超过 60,000 个 UTF-16 单元。服务端复用现有 Gemini 配置、传输及进程内去重，使用独立关系提示词和 `gemini-connection-1` 结果契约；不自动重试。最多返回一条候选关系，附说明和两端原文依据；无候选时必须有原因。前后端核对身份、原文副本和逐字 UTF-16 引用，引用不能拆开代理对；这些检查不证明语义结论正确。

候选以虚线展示，只有“保留关系”才写入 IndexedDB 并改为实线；拒绝或关闭不保留候选。已收到候选但保存失败时保留候选供再次保存，不再调用模型。等待期间取消、改选、内容变化或关闭白板会使迟到结果失效；停止等待不保证撤销供应商处理或计费。进入本地保存后的结果以实际事务提交为准，不把关闭界面当作已撤回保存。

数据库当前为 v8，保留原六个仓库和旧数据，新增 `canvasNotes`、`canvasConnections`。便笺 `revision` 在每次保存时递增并用作跨标签写入锁，`version` 只随标题／正文变化递增；纯位置变化不使关系过期。保存关系在同一事务检查两端已存标题、正文及内容版本，相同便笺对与版本不重复连线。修改内容使未保留候选失效，已有关系显示“待复核”，其分析副本与依据保留。移除便笺需确认，并与关联连线原子删除；单独移除连线保留两端便笺。同源标签通过通知与重新聚焦刷新数据，冲突不会覆盖其他标签已保存的修改。

此节描述当前源码；既有便携 ZIP 尚未为 PDF-01 重打。本轮关系验证使用模拟模型响应，未验收 Canvas 真实模型调用或用户观感。

## 本地 Check 的限制

本地规则只识别同月无年份的“活动于11月8日开放。海报于11月10日定稿，随后开放报名。”这类明确句式，可含“计划”和日期空格。不早于活动开放的海报定稿时间会触发核对提示，同日不推断具体时刻。其他日期、已识别的取消标记或不支持的结构会返回规则不支持。不是通用语义检查，不能覆盖任意否定、反事实、事件归属或遗漏。

补充要求仅记录，不会被规则解释。结果不自动覆盖正文。单次材料上限 60,000 个 UTF-16 单元；只发送到浏览器本地规则函数，不发送到模型或后端。旧结果保留旧材料副本，点击“再次检查当前全文”后仍需确认提交。

数据库当前为 v8，保留已有材料、布局、设置、处理记录、任务、关注和熔炉成员，新增白板便笺与关系仓库。历史上 v6 新增熔炉仓库，v7 不改仓库结构或旧记录，只隔离不能识别新 Gemini 结果的旧客户端。升级前保存草稿、结束任务和关注、关闭旧标签页。若提示其他 Wisp 标签页阻塞升级，请先保存或复制那些页面中的草稿，再关闭其他标签页、刷新当前页面；不要清除浏览器数据。本地检查同步计算、原子保存，没有后台队列或关闭页面后继续运行的能力。

## 本地 Understand 与 Create

Understand：确认选区或全文后点击“整理原文摘录”。按原文顺序取前 8 个非空行（简短模式为 3 行），去掉行首尾空白，展示原文位置及剩余行数；不是语义摘要，不判断哪些内容更重要。

Create：确认材料后点击“生成模板草稿”。当前提供一套活动介绍模板，只识别独占一行的以下字段（中文或英文冒号均可）：

    主题：周末读书会
    时间：周六 19:00
    地点：书店阅读区
    参与方式：提前预约

字段缺失显示“待补充”，重复显示“待确认”，不会从其他正文猜测字段。介绍正文保留待补充占位；固定模板提示与材料字段分开，不宣称生成了创意内容。普通段落材料也可以运行，但无法匹配字段时得到待填写模板。

## 一次性 Summon

巡读蝠复用 Check，书页灵复用 Understand，炼金灵复用 Create。任务使用确认时的材料副本；本地模式的补充要求只记录，Gemini 模式的三种使魔会把补充要求提交给模型，Page Sprite 另提交摘要设置。完成回信可复制，不自动改正文。

## Proposal 与摘录偏好

可选择简短 3 行或标准 8 行；之后直接 Understand 与 Page Sprite 的确认面板采用该默认值，也可仅修改本次。About you 展示明确确认的偏好并支持忘记。偏好刷新后保留、同源页面同步；旧结果及已提交任务保留当时行数，不因偏好变化而改写。

触发计数按本次页面生命周期累计，不跨标签页合并，刷新清零。历史回看、任务恢复、失败或召回不计入；同一提交 ID 不重复计数。暂时不用、取消确认或忘记后本会话不重问。待展示/展示提议十分钟过期，规则保留 60 秒展示冷却；摘录偏好本会话最多出现一次；与联合整理、持续关注提议共用 60 秒展示冷却。关闭开关清除未接受的提议，不取消已授权使魔任务。

这是可解释的本地规则邀请，不是用户意图推断或语义摘要。Proposal 候选只留在当前页面内存，不持久化行为轨迹；用户确认后保存偏好或关注授权，关注授权包含全文起点副本，处理记录按原机制保存材料副本。实现清单及验证见 contracts/proposal.md。

## 两份文本联合整理提议

开启 Helpful proposals 后，在两分钟内来回激活两份文本窗口。例如按底部文档按钮依次点击“书店活动提案 → 场地说明 → 书店活动提案 → 场地说明”；只计算真正切换，重复点击当前窗口不计入。启动布局恢复不会触发。两份材料都必须非空且各不超过 60,000 UTF-16 单元。

邀请阶段任一材料修改或十分钟过期会使提议失效；接受后则保持确认副本，可显式更新两份当前全文。暂时不用、取消、完成或失效后，同一材料对本会话不再提议。刷新开始新会话，已有结果不丢失。已有摘录偏好不会禁用联合提议，两类提议不会同时展示。不读取 Sheets 或外部软件，不新增使魔任务或模型调用。文件与验收记录见 contracts/joint-proposal.md。


## Check 后的持续关注

1. Settings 开启 Helpful proposals，对支持的日期句式主动执行本地 Check（也支持本地一次性 Scout Bat 的成功回信；Gemini 结果不触发关注邀请）。
2. 关闭结果或魔法书后，在邀请中点击“查看关注范围”；确认全文与页面运行边界，再点击“确认开始关注”。
3. 修改并保存此文档后，Scout Bat 对稳定的新版本运行本地 Check；右侧显示关注数与未读回信。魔法书 Familiars 展示关注授权、关联版本任务与回信。
4. 点击“停止关注”停止后续检查并召回尚未完成的关联任务；已有回信保留。关闭 Helpful proposals 只关闭邀请，不能替代停止关注。
5. 关闭或刷新发起页面后中断，不由其他标签页接管，也不自动恢复。需要继续时，在 Familiars 点击“重新确认关注”并再次确认全文。

每份材料同页最多邀请一次，拒绝、取消、完成、过期或材料变化使邀请失效后均不重问。刷新开启新的邀请会话，但旧关注不会因此自动恢复。当前按已保存版本变化触发；连续编辑合并到较新的稳定版本，不保证检查每次按键。空白或超出 60,000 UTF-16 单元的版本会注明跳过，后续有效版本继续；失败版本不无限重试。浏览器休眠或后台节流可能延迟检查。

只读取 Wisp 本地文档，不监控外部网页或文件，检查仍受有限日期规则约束。详细实现文件、事务边界与验收见 contracts/watch-proposal.md。


## Idea Cauldron · 本地文本版

点击顶栏“灵感熔炉”。可以新建空白材料、粘贴文本（可填来源备注），或导入一份 TXT／DOCX／PPTX／XLSX／PDF；文字预览可编辑，点击“确认加入”才保存。新建后打开编辑窗口，粘贴/导入后只选中材料，不铺开新窗口。

“熔炉中的材料”最多 12 份，旧示例不自动占名额；“全部本地材料”还包括示例及已移出的材料。移出只腾出容器名额，不删除材料、结果、任务或关注；可以重新加入。首轮没有永久删除或完整备份导出。

原单材料入口继续进入原有确认和结果／回信流程，默认全文、不沿用其他编辑器选区。PDF-05 分支新增“勾选多材料”：明确选择 2～12 份熔炉成员，确认页逐份全文／选段，合计最多 60,000 UTF-16，再提交一次 Gemini 综合处理。每份快照及引用独立保留；前台一条批次记录，使魔一条批次回信。旧两份联合整理仍是本地分别摘录，不作为语义综合。完整边界见 [多材料契约](../contracts/multi-material.md)。

所有文件上限 20 MB（20,000,000 bytes），新加入的正文最多 60,000 UTF-16 单元；超限、解码失败、NUL 或纯空白明确拒绝，不静默截断。TXT 继续浏览器严格 UTF-8（允许 BOM）解码；复杂格式通过本机 `/api/import-text` 提取，不调用 Gemini。DOCX 正文与表格、PPTX 幻灯片文字与表格、XLSX 工作表行列（公式不计算）、PDF 已有文字层转为文字副本，展示未转换内容提示。页码／幻灯片号／工作表标记保留；PDF 不含 OCR。换行统一 LF，预览编辑和确认保存仍检查文字上限。粘贴正文同样限制长度；新建可为空，空白不能处理。已有正文不被截断，超长全文仍受能力限制。

来源保存原文件名、字节数、文件修改时间、格式、导入时间与解析提示；TXT 另保留 UTF-8 编码。改材料标题不会改变来源。文件是可编辑本地副本，不保存原二进制、文件路径或句柄，不监视/回写磁盘文件。持续关注只跟踪该副本在 Wisp 中的已保存版本。粘贴来源备注由用户填写，不代表核实出处。历史快照缺少来源时明确提示，不补造记录。

复杂格式由一次性 Python 子进程解析，30 秒解析限时、最多 2 个并发导入；取消或断连会清理该进程。损坏／加密／无文字／不支持／超限有独立提示。详细解析范围、压缩内容和页数限额、来源契约与复现步骤见 [文件导入契约](../contracts/import-text.md)。本轮不改 IndexedDB v8，不增加原文件同步、OCR 或拖放。

只有材料落盘后才显示加入成功；首次保存失败保留输入供重试。新增表单尚未确认时，关闭会提醒先确认或取消；刷新/离开仍可能丢失未提交输入。编辑沿用自动保存和冲突保护。窗口布局沿用 150ms 防抖，刷新前应等待布局写入；窗口状态不影响材料保存。

同源标签页同步成员、新材料及未打开材料的已保存更新。有编辑窗口、待保存或失败的本页材料保留自己的版本，发生冲突时仍需复制草稿后重新载入，不强制覆盖。列表点击不触发联合整理提议。详见 contracts/cauldron.md 与 docs/cauldron-verification.md。

### Gemini Understand / Create 新输出

Understand 使用独立 brief/standard 摘要设置，默认standard，仅本次使用；显示概述、要点与精确原文依据，材料不足时显示待补充信息。它与本地3/8行摘录偏好互不代替。
