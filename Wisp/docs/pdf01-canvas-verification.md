# PDF-01 白板与连线验证

日期：2026-10-18。范围：Canvas 纯文本便笺、两张多选、显式 Gemini 关系分析、候选确认、本地保存与版本变化。代理配置及其他 PDF 待办未改动。

## 已实现

- 底部 Canvas 打开工作面；新建／粘贴／编辑／移动／移除便笺。支持拖动、方向键和侧栏坐标输入。
- Shift 或复选框选择两张。Helpful proposals 开启后稳定选择一秒邀请，与已有提议共享互斥和 60 秒冷却。拒绝不请求，同对同版本本会话不重复邀请；手动按钮仍可使用。
- 点击才 POST `/api/connections`，发送两份冻结标题／正文／版本。正文合计最多 60,000 UTF-16 单元；至多一个候选，需要两端逐字引用。空结果和错误分别呈现。
- 候选虚线、解释及双端引用；确认后本地保存为实线。关系保存失败可重试，不重复调用模型。
- IndexedDB v8 保留旧数据，新增 `canvasNotes`、`canvasConnections`。内容版本与每次保存的 revision 分开；移动保留关系，内容变化使候选失效、已存关系待复核。确认事务核对两端快照；删除便笺原子级联移除连线。
- 跨标签同步、编辑冲突保留草稿、关闭取消及迟到保护；本地写／删成功后即使重读失败，也立即使旧结果失效。
