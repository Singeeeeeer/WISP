# PDF-02 复杂格式导入验证

日期：2026-10-18。范围：TXT／DOCX／PPTX／XLSX／PDF 单文件文字导入、可编辑预览、确认保存、来源及三能力兼容。拖放与 OCR 不在本项范围。

## 实现

- 熔炉“导入文件”复用现有新增流程；TXT 浏览器解码，复杂格式送本机 Python，不需要 Gemini 配置。
- DOCX 正文／表格，PPTX 幻灯片文本框／组合／表格，XLSX 工作表行列及原公式，PDF 已有文字层。位置标记和未转换内容提示供用户核对；预览可修改，确认才创建一份材料。
- 20 MB／60,000 UTF-16，空白、损坏、加密、不支持、超限有明确错误；格式内容、压缩包与解析时间限制见 [导入契约](../contracts/import-text.md)。
- 文件名、大小、原修改时间、导入时间和提示随来源保存。四种新来源同时兼容前后端三能力契约与快照；原文件不回写，不保存原二进制，不改变数据库 v8。
- 读取停止、取消新增、组件卸载与迟到响应保护；保存失败保留编辑后的预览，使用同一标识重试，不重新解析。
